Struct CellExt 

Source 
pub struct CellExt(/* private fields */);
Expand description

Out-of-band data attached to a Cell.

Backends write extensions around the cell’s symbol as run state. Extensions never affect the symbol’s text or width. Currently the only extension is a Hyperlink.

A CellExt is a cheap to clone, reference-counted handle, so applying the same extension to many cells shares a single allocation, and comparing two cells that share it costs a pointer comparison. Values are immutable: with_hyperlink returns a new value (copying the data only when it is shared).

§Example

use ratatui_core::buffer::{Cell, CellExt, Hyperlink};

let ext = CellExt::from(Hyperlink::new("https://ratatui.rs"));
let mut cell = Cell::new("r");
cell.set_ext(Some(ext.clone()));
assert_eq!(cell.ext(), Some(&ext));
assert_eq!(
    cell.hyperlink().map(Hyperlink::uri),
    Some("https://ratatui.rs")
);
