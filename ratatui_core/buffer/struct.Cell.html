pub const fn new(symbol: &'static str) -> Self

Creates a new Cell with the given symbol.

This works at compile time and puts the symbol onto the stack. Fails to build when the symbol doesn’t fit onto the stack and requires to be placed on the heap. Use Self::default().set_symbol() in that case. See CompactString::const_new for more details on this.

pub fn merge_symbol( &mut self, symbol: &str, strategy: MergeStrategy, ) -> &mut Self

Merges the symbol of the cell with the one already on the cell, using the provided MergeStrategy.

Merges Box Drawing Unicode block characters to create a single character representing their combination, useful for border collapsing. Currently limited to box drawing characters, with potential future support for others.

Merging may not be perfect due to Unicode limitations; some symbol combinations might not produce a valid character. MergeStrategy defines how to handle such cases, e.g., Exact for valid merges only, or Fuzzy for close matches.

If the cell has no symbol set, it will set the symbol to the provided one rather than merging.

§Example
use ratatui_core::symbols::merge::MergeStrategy;

assert_eq!(
    Cell::new("┘")
        .merge_symbol("┏", MergeStrategy::Exact)
        .symbol(),
    "╆",
);

assert_eq!(
    Cell::new("╭")
        .merge_symbol("┘", MergeStrategy::Fuzzy)
        .symbol(),
    "┼",
);

pub fn set_symbol(&mut self, symbol: &str) -> &mut Self

Sets the symbol of the cell.

With the cell-extensions feature, this also removes the cell’s extension (such as a hyperlink), because the extension belongs to the content it was attached to. Text drawn over a link, such as a popup, is therefore not linked. Attach extensions after drawing the content, e.g. with Buffer::set_hyperlink.

pub fn set_hyperlink(&mut self, hyperlink: Option<&Hyperlink>) -> &mut Self

Sets or removes the hyperlink of the cell, keeping any other extension data.

This doesn’t add an id to the link. To link several cells as one link, prefer Buffer::set_hyperlink, which also shares one allocation between the cells.

§Example
use ratatui_core::buffer::{Cell, Hyperlink};

let mut cell = Cell::new("r");
cell.set_hyperlink(Some(&Hyperlink::new("https://ratatui.rs")));
assert_eq!(cell.hyperlink().unwrap().uri(), "https://ratatui.rs");

// writing a new symbol removes the link
cell.set_symbol("x");
assert_eq!(cell.hyperlink(), None);

Sets the cell to be skipped when copying (diffing) the buffer to the screen.

This is helpful when it is necessary to prevent the buffer from overwriting a cell that is covered by an image from some terminal graphics protocol (Sixel / iTerm / Kitty …).

impl CellWidth for Cell

Source§

fn cell_width(&self) -> u16

Returns CellDiffOption::ForcedWidth when set, otherwise computes the width from the cell’s symbol.

A cell holds a single grapheme cluster, so the unicode width of its symbol is the number of columns it takes on screen. Low-level callers can store anything in a symbol though, and image protocols store a whole escape sequence there while still occupying a single column. Such a symbol has no meaningful unicode width, so it counts as one column. Use CellDiffOption::ForcedWidth to declare the real width of these cells.
