The widgets module contains the Widget and StatefulWidget traits, which are used to render UI elements on the screen.

Traits§

StatefulWidget
A StatefulWidget is a widget that can take advantage of some local state to remember things between two draw calls.
Widget
A Widget is a type that can be drawn on a Buffer in a given Rect.
