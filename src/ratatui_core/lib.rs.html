8//! **ratatui-core** is the core library of the [ratatui] project,
9//! providing the essential building blocks for creating rich terminal user interfaces in Rust.
10//!
11//! [ratatui]: https://github.com/ratatui/ratatui
12//!
13//! # Why `ratatui-core`?
14//!
15//! The `ratatui-core` crate is split from the main [`ratatui`](https://crates.io/crates/ratatui)
16//! crate to offer better stability for widget library authors and advanced integrations. Widget
17//! libraries should generally depend on `ratatui-core`, benefiting from a stable API and reducing
18//! the need for frequent updates.
19//!
20//! Most applications, on the other hand, should depend on the main `ratatui` crate, which
21//! includes built-in widgets, backend re-exports, and higher-level setup helpers.
22//!
23//! In practice:
24//!
25//! - Use [`ratatui`] to build applications.
26//! - Use `ratatui-core` to implement widgets, backend integrations, or other code that needs the
27//!   core rendering and layout contracts directly.
28//!
29//! # Installation
30//!
31//! Add `ratatui-core` to your `Cargo.toml`:
32//!
33//! ```shell
34//! cargo add ratatui-core
35//! ```
36//!
37//! # Crate Organization
38//!
39//! `ratatui-core` is part of the Ratatui workspace that was modularized in version 0.30.0 to
40//! improve compilation times, API stability, and dependency management. This crate provides the
41//! foundational types and traits that other crates in the workspace depend on.
42//!
43//! **When to use `ratatui-core`:**
44//!
45//! - Building widget libraries that implement [`Widget`] or [`StatefulWidget`]
46//! - Building custom integrations on top of Ratatui's core rendering contracts
47//! - You want minimal dependencies and faster compilation times
48//! - You need maximum API stability (core types change less frequently)
49//!
50//! **When to use the main [`ratatui`] crate:**
51//!
52//! - Building applications
53//! - You want built-in widgets, backend re-exports, and setup helpers such as `ratatui::run`
54//!
55//! For detailed information about the workspace organization, see [ARCHITECTURE.md].
56//!
57//! [`ratatui`]: https://crates.io/crates/ratatui
58//! [`Widget`]: widgets::Widget
59//! [`StatefulWidget`]: widgets::StatefulWidget
60//! [ARCHITECTURE.md]: https://github.com/ratatui/ratatui/blob/main/ARCHITECTURE.md
