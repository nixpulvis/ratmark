HTML rendering that matches kramdown’s output, attributes included.

Mirrors pulldown_cmark::html: the same functions, but taking the (Event, Attributes) pairs from Document::events instead of bare events.

use pulldown_kram::{Document, Extensions, html};

let document = Document::new("# Hi\n\nSee *this*{:.new}.\n", Extensions::all());
let mut out = String::new();
html::push_html(&mut out, document.events());
assert_eq!(out, "<h1 id=\"hi\">Hi</h1>\n<p>See <em class=\"new\">this</em>.</p>\n");

As in kramdown, footnotes are numbered in the order they’re first referenced and rendered at the end, with links back to each reference. Footnote definitions are held until then; everything else is written as it arrives. Math alone in its paragraph is written as \[…\], and inline math as \(…\), for MathJax to render. Code isn’t highlighted: a code block’s language becomes a language-… class on its <code>. Empty table cells contain a no-break space. Raw HTML in the document is written unchanged.

kramdown’s converter options, like footnote_nr, aren’t supported, nor are the ids kramdown gives the links in tables of contents. References to undefined footnotes can only occur with pulldown-cmark’s ENABLE_OLD_FOOTNOTES, and link nowhere.
