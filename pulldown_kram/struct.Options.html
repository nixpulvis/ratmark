Struct Options

Expand description

Parsing options for a Document: which kramdown extensions to enable, plus any extra pulldown-cmark options.

Each part of kramdown’s syntax has an Extensions flag, so Extensions::all() matches kramdown, and converts into Options with no extra pulldown-cmark options. Some extensions, like tables, are implemented by pulldown-cmark and turn on its matching option. Those options are controlled by their extension alone, and are on exactly when it is, regardless of cmark. Use cmark for syntax kramdown doesn’t have, like GitHub’s > [!NOTE] blockquotes from ENABLE_GFM.

cmark can’t turn on ENABLE_TABLES, ENABLE_FOOTNOTES, ENABLE_STRIKETHROUGH, ENABLE_TASKLISTS, ENABLE_SMART_PUNCTUATION, ENABLE_DEFINITION_LIST or ENABLE_MATH, which are controlled by the extensions, or ENABLE_HEADING_ATTRIBUTES, which parses {…} after a heading differently from kramdown. ENABLE_OLD_FOOTNOTES only has an effect with Extensions::ENABLE_FOOTNOTES.

use pulldown_kram::{Document, Extensions, Options};
use pulldown_kram::pulldown_cmark::Options as Cmark;

// Plain kramdown.
let kramdown = Document::new("a | b\n-|-\n", Extensions::all());

// Plus GitHub's `> [!NOTE]` blockquotes.
let more = Options::new(Extensions::all(), Cmark::ENABLE_GFM);
let document = Document::new("> [!NOTE]\n> a\n", more);
