Following a terminal’s mouse wheel with Gestures.

A terminal reports the wheel a tick at a time, up, down, left or right, and a trackpad swipe that’s a little diagonal sends ticks both ways. A Wheel keeps each gesture going one way, so the swipe goes either up and down or sideways, not both.

It counts time with std’s Instant, so it isn’t built for wasm32-unknown-unknown, which has no clock for it. In a browser, use the web feature’s web::listen instead.
