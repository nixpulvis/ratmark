Module front_matter 

Source
Expand description

A preamble of metadata at the very top of a file, fenced off from the document after it. Static site generators like Jekyll and Hugo read it from Markdown for a page’s title, date, tags and layout, and it isn’t meant to be shown as part of the page.

Each language it can be written in has its own feature:

  • front-matter-yaml: YAML between --- lines
  • front-matter-toml: TOML between +++ lines

Nothing else in ratmark looks for front matter. It’s a prepass: FrontMatter::split it off, give the body to MarkdownState or Rendered::render, and FrontMatter::deserialize the front matter into your own serde type.

use ratmark::front_matter::FrontMatter;
use serde::Deserialize;

#[derive(Deserialize)]
struct Meta {
    title: String,
    tags: Vec<String>,
}

let (front, body) = FrontMatter::split("---\ntitle: 'Hi: there'\ntags: [a, b]\n---\n\n# Hi");
let meta: Meta = front.unwrap().deserialize().unwrap();
assert_eq!(meta.title, "Hi: there");
assert_eq!(meta.tags, ["a", "b"]);
assert_eq!(body, "\n# Hi");
